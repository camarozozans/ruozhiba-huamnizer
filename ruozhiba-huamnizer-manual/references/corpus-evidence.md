# 语料证据

三份文件不是同一种东西，混着学就会学歪。

## 各是什么

| 文件 | 条数 | 字段 | 平均回答 | 中位回答 |
|---|---|---|---|---|
| `ruozhiba-train.json` | 9408 | `content` / `reply` | 31.3 字 | 19 字 |
| `ruozhiba-val.json` | 800 | `content` / `reply` | 32.0 字 | 20 字 |
| `ruozhiba_qa.json` | 1496 | `instruction` / `output` | 91.7 字 | 89 字 |

前两份是同一来源的原始贴吧抓取，只是切了 train 和 val，加起来 10208 条。

第三份量级完全不同：回答长度是前两份的三到四倍，风格是「先承认字面义，再拆解，再解释」。它不是弱智吧的语气，是「AI 认真回答荒谬问题」的语气。

## 人在打字时极短

10208 条回复里，中位数 19 字，平均 31.3 字（被少量长贴拉高），647 条不超过两个字。

19 字什么概念：一句「我真是服了这破电脑」是 11 个字。

这条数据是「短」的直接依据。人味的第一物理特征就是短，不是幽默。

`qa` 那份的中位 89 字正好是反面参照，它的长度和「像 AI」是同一件事。分布是：10% 分位 33 字，25% 分位 58，50% 分位 89，75% 分位 119，90% 分位 146。只有 14%（210 条）落在 40 字以内。

## 18% 是噪声

`train` 加 `val` 里有 1844 条（18.1%）的 `reply` 和 `content` 一模一样，抓取时把帖子标题当成了回复。

```
{"content": "你下楼的时候，楼正在上你", "reply": "你下楼的时候，楼正在上你"}
{"content": "手机充电器插进去220V出来5V，剩下的215V哪去了？", "reply": "手机充电器插进去220V出来5V，剩下的215V哪去了？"}
```

这些不是风格，是数据错误。照着学只会学到复读。

`qa` 那份回音率 0%，每条 `instruction` 都有独立的 `output`。这是它唯一的格式优势。

## 12.4% 不能学

低俗擦边关键词粗筛（屎、尿、操、逼、脱、裸、强、奸、啪、妹、丁丁 之类），`train` 加 `val` 里 1268 条至少命中一个。

高频的是 `性` 313、`屎` 209、`强` 148、`尿` 117、`脱` 99、`操` 90。这是贴吧语境下自嘲和互损的语言，不能对外复用。`mechanisms.md` 第七条「反向自洽」的原例大量带这类内容，所以那一条的引用全部做了替换。

## 样本分级

可以直接当范本用的，短、字面、不解释：

```
剩一个心脏还能活吗？        → 能，人本来就只有一个心脏。
什么鸡没有翅膀？            → 菜鸡。
男人怀孕叫什么？            → 男人不能怀孕，所以没有专门的称呼。
蓝牙会得龋齿吗              → ？
面对泪如雨下的小明          → 王老师赶紧跑回家收衣服。
恐高症会害怕去高中吗        → 不会。恐高是怕高处，跟去高中读书没关系。
```

共同点是一个字都不多余，而且全部咬着对方原话里的那个词：心脏、翅膀、怀孕、龋齿、雨、高中。没有一个另起话题。

结构可学但内容要换的：

```
小明11岁，哥哥大3岁，每天吃三个苹果，什么时候超过哥哥？ → 永远不可能，哥哥始终大3岁。
我爸我妈结婚日期是同一天，当初为什么不问我           → 他们当然同一天结婚，那时你还没出生。
鬼压床这么久怎么没裁判读秒判负                       → 因为鬼压床不是比赛。
```

这三条是「拒绝上钩」加「顺前提」，机制库里最适合迁移到日常对话的部分。

丢弃的：Q 等于 A 的回音（1844 条）、没有上下文的单字回复、抓断的长贴（最长 432 字，末尾截断）。

反面教材是 `qa` 里那些一本正经的长解释。信息正确，结构完整，读完不知道是谁在说话，正是本技能要消除的东西。有意思的是同一份文件里也藏着范本，上面六条有三条来自它。这说明长度不是问题，铺垫才是：短的那几条里没有「首先」「其次」「值得注意的是」。

## 能迁移的四条

短是硬指标，中位 19 字，超了就砍。

一拍就停。最好的回复只推进一格，不解释，不补充，不反转第二次。

长在对方的话上。范本全部抓住对方原句里的一个具体词，不另起话题。

噪声占三成。18% 复读加 12% 低俗，加起来三成不能用。从语料直接训练会学到大量垃圾，必须人工分层，机制库就是分层的结果。
